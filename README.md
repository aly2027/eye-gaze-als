# EYEUM (눈빛이음)

**Website: [eyeum.org](https://eyeum.org)**

EYEUM is a camera-based eye-gaze communication app for people with ALS. It uses only eye movements on a standard tablet to build and speak sentences. This site provides downloads, setup guides, and feedback.

EYEUM (눈빛이음) es una aplicación de comunicación con la mirada para personas con ELA. Funciona con la cámara de una tableta o un teléfono normal: con solo mover los ojos se forman frases que el dispositivo dice en voz alta. En este sitio puede descargar la aplicación, leer las guías de instalación y enviarnos su opinión.

# EYEUM (눈빛이음)

**Website: [eyeum.org](https://eyeum.org)**

EYEUM is a camera-based eye-gaze communication app for people with ALS. It uses only eye movements on a standard tablet to build and speak sentences. This site provides downloads, setup guides, and feedback.

EYEUM(눈빛이음)은 ALS 환자를 위한 카메라 기반 시선 의사소통 앱입니다. 일반 태블릿에서 눈의 움직임만으로 문장을 만들고 음성으로 말할 수 있습니다. 이 사이트에서 앱 다운로드, 설치 안내, 의견 보내기를 이용할 수 있습니다.

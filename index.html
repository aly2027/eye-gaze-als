Powerful, simple

Low-cost communication that asks the least of the patient.

EYEUM pairs camera-based eye tracking with a board where the words you use most are always the fastest to reach.

Camera-based eye tracking

Uses the front camera of a standard phone or tablet, and only left and right eye movements. No headset, no infrared rig, no calibration lab required.

Frequency-ordered board

The words and phrases you use most sit within the fewest glances, so everyday communication comes out faster.

Speaks out loud

Each completed word is read aloud with built-in text-to-speech, so caregivers hear it instantly.

Made for real use

Large targets, high-contrast text, and quick caregiver phrases designed with accessibility first — not as an afterthought.

How it works

From a short code to a spoken word.

Read the word's code

Every word on the board carries a short binary code — 0 for a glance left, 1 for a glance right. The patient finds the word they want and reads its code.

Build the code with left and right

A glance to the left adds a 0, a glance to the right adds a 1. Each digit appears on screen as it is entered, so the code can be followed as it forms.

Hold the center to speak

Gazing at the center for about two seconds completes the code. If it matches a word in the book, the app speaks it aloud through the device speaker.
